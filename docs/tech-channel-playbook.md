# Faceless Tech Channel: Step-by-Step Playbook

Decision on 4 October 2026: the primary channel is a faceless AI-automation tutorial
channel. No face on camera, ever. Screen recordings carry the video, a voice carries
the explanation, Higgsfield makes hooks, B-roll and thumbnails.

The history channel (Tales Before Time) is paused, not cancelled. Its kit stays in
`docs/storybook-channel-launch-kit.md`.

---

## Part A. One-time setup (week 1)

### Step 1. Pick the name

**Primary: simpler than that.** Every title becomes a sentence: "automating invoices is
simpler than that". Lowercase, friendly, signals the promise.

| Option | Handle to try | Why |
|---|---|---|
| simpler than that | @simplerthanthat | the title formula is built in |
| the lazy automator | @thelazyautomator | strong hook for busy people |
| zero click work | @zeroclickwork | promise of work that runs itself |
| automate it plainly | @automateitplainly | clear, calm, trustworthy |

Check the handle on YouTube, Instagram, X, LinkedIn and a .com or .in domain. Take the
first name that is free on YouTube and the domain. Do not spend more than a day on this.

### Step 2. Define who it is for and what it promises

| Item | Lock |
|---|---|
| Audience | small-business owners, freelancers and office workers who repeat boring computer tasks. English, global. |
| Promise | One real task automated with AI per video, start to finish, no coding needed. |
| Banner line | Boring work, automated. One real build every week. |
| About text | Every video automates one real task with AI tools, recorded start to finish on screen. No hype, no face, just the build. Narration may use an AI voice, disclosed on each video. Templates for every build are linked in the description. |

### Step 3. Create the channel

1. Make a new Google account just for the channel. Keep personal email separate.
2. On YouTube, create the channel with the chosen name and handle.
3. Verify the phone number in YouTube Studio settings. This unlocks custom thumbnails and videos longer than 15 minutes.
4. Upload a logo and a banner. Make both in Higgsfield with one prompt each, same colours.
5. Paste the About text, add the domain and a link to the template store once it exists.
6. In Studio, set upload defaults: category Science & Technology, language English, comments on, and a default description footer (Step 15).
7. Create three playlists: Automate Your Business, AI Tools Tested, Quick Wins (Shorts).

### Step 4. Brand lock (never change for the first 20 videos)

| Element | Lock |
|---|---|
| Colours | one dark background, one bright accent, white text |
| Font | one bold sans-serif for thumbnails and on-screen text |
| Thumbnail layout | left: the boring task (messy), right: the result (clean), arrow between, 3 words max |
| Title formula | "[Task] is simpler than that" or "I automated [task] in [time]" |
| Intro | no channel intro, no "welcome back". The video opens on the result. |
| Outro | 10 seconds: "the template is in the description" plus an end screen to the next video |

### Step 5. Set up tools

| Job | Tool | Cost |
|---|---|---|
| Screen recording | OBS Studio | free |
| Editing | DaVinci Resolve or CapCut desktop | free |
| Microphone, if using your voice | any USB condenser mic | about ₹2,500 to ₹4,000 once |
| Voice cleanup | Adobe Podcast Enhance or Resolve's voice isolation | free |
| AI voice, if not using yours | ElevenLabs, or the voice tools inside Higgsfield | about $5 to $22 a month |
| Scripts | Claude | existing |
| Hooks, B-roll, thumbnails | Higgsfield | plan of your choice |
| Music | YouTube Audio Library | free |
| Captions | CapCut auto captions or YouTube auto captions, corrected | free |
| Template store | Gumroad or Lemon Squeezy | free until you sell |
| Keyword ideas | YouTube search autocomplete, vidIQ free tier | free |

Voice choice: your own voice builds trust faster and has zero policy risk. An AI voice is
allowed and monetisable but must be disclosed. Pick one now and never switch.

### Step 6. Prepare a clean recording setup

1. A separate browser profile with no bookmarks, no personal tabs, no saved logins visible.
2. Screen resolution 1920x1080 or 2560x1440. Browser zoom 125%. Editor font size 16 or larger.
3. Dark mode everywhere, to match the brand.
4. A demo Gmail, a demo Google Sheet and demo data. Never show real customer data.
5. A notes file listing every API key and email to blur in editing.
6. OBS: one scene, display capture, 30 fps, MKV recording remuxed to MP4, microphone on a separate track.

## Part B. Every video, step by step (about 8 hours per long video)

### Step 7. Find the idea (30 min)

Good idea test, all four must be yes:
1. A real person does this task by hand every week.
2. People search for it. Type the task into YouTube search and check the autocomplete suggestions and the view counts of existing videos.
3. You can build it in under two hours with tools that have free tiers.
4. The result is visible on screen in one shot (an inbox emptying, a sheet filling, a message sending).

Places to mine ideas: Reddit r/smallbusiness, r/freelance, r/excel and r/automation;
YouTube comments on bigger automation channels; your own work tasks; the "people also ask"
box in Google.

### Step 8. Build it for real first (1 to 2 hours)

Do the whole build off camera once. Write down every click and every mistake. The mistakes
become the "watch out for this" moments in the video, and they are what viewers thank you
for. Time it. The time becomes the title.

### Step 9. Write the script (1 hour)

Ask Claude for a first draft from your build notes, then rewrite it in your words.
Structure for an 8 to 12 minute video:

| Section | Length | Content |
|---|---|---|
| Hook | 0:00-0:20 | Show the finished result running. Say what it saves. |
| Promise | 0:20-0:40 | What they will have by the end, and that the template is free or linked. |
| The problem | 0:40-1:30 | The manual way, shown quickly. Make the pain visible. |
| The build | 1:30-9:00 | 4 to 6 steps. One step per chapter. Show each click. Explain why, not only what. |
| The gotcha | inside the build | The mistake you hit, and the fix. |
| The test | 9:00-10:00 | Run it end to end with fresh demo data. |
| Next step | 10:00-10:30 | One idea to extend it, the template link, the next video. |

Keep sentences short. Read it aloud once. Anything you stumble on, rewrite.

Crossing 8 minutes matters: it unlocks mid-roll ads, roughly doubling revenue per view.
Never pad to get there. Add a real second use case instead.

### Step 10. Record the screen (1 hour)

1. Restart the computer, close everything, turn on Do Not Disturb.
2. Record each script section as its own clip. Small clips are easy to redo.
3. Move the mouse slowly. Pause one second before and after each click.
4. Re-record any section with a mistake you did not plan to show.
5. Record 10 seconds of the final result running, for the hook.

### Step 11. Record the audio (30 min)

**Own voice:**
1. Small room, soft furnishing, mic 15 cm from the mouth, slightly off-axis.
2. Record section by section from the script, standing up for energy.
3. Clean with Adobe Podcast Enhance or Resolve voice isolation.
4. Target loudness about -14 LUFS, the YouTube standard.

**AI voice:**
1. Choose one voice and keep it forever. Calm, mid-pace, clear.
2. Paste the script section by section, regenerate any line with odd stress.
3. Tick "altered or synthetic content" when uploading if a viewer could mistake it for a real person, and say "narration uses an AI voice" in the description either way.

### Step 12. Make the Higgsfield pieces (30 min)

| Piece | Use |
|---|---|
| 5-second hook clip | a cinematic shot of the "before" pain, e.g. a desk buried in invoices |
| 2 or 3 concept clips | Editorial Motion Graphics clip to explain an idea like "a trigger" or "an AI agent" |
| Thumbnail | the thumbnail workflow, using the locked layout |

Keep generated footage under 20% of the video. The screen recording is the product.

### Step 13. Edit (2 hours)

1. Lay voice down first, then fit screen clips to the voice.
2. Cut every pause and every wait for a page to load.
3. Zoom in on each click target. The viewer should never squint.
4. Blur every key, email and personal detail from the notes file.
5. Add on-screen step labels: "Step 2 of 5: connect Gmail".
6. Add captions, music at low volume under the hook and outro only.
7. Export 1080p or 1440p, 30 fps, H.264, high bitrate.
8. Watch the whole export once at normal speed before uploading.

### Step 14. Thumbnail and title (30 min)

- Thumbnail: messy task on the left, clean result on the right, three words such as "INVOICES: AUTOMATED". Same layout every time.
- Title: the formula, under 60 characters, the task word first. Examples: "I automated my invoices in 20 minutes (no code)", "booking replies are simpler than that".
- Write three titles, pick the one you would click.

### Step 15. Upload (20 min)

Description template:

```
[One sentence: what this builds and what it saves.]

Free template for this build: [link]
Need this built for your business? [link to services page or email]

Chapters
0:00 The result
0:20 What you'll build
0:40 The manual way
1:30 Step 1: ...
...
10:00 What to build next

Tools used (some links are affiliate links, which support the channel at no cost to you):
- [tool]: [link]

Narration uses an AI voice. [delete if your own voice]

#automation #ai #nocode
```

Then: add to a playlist, add end screen and a card to a related video, set schedule to
Tuesday or Wednesday morning US Eastern time, which is evening in India.

### Step 16. Cut three Shorts (30 min)

1. The 20-second hook with the result.
2. The one gotcha and its fix.
3. The "before vs after" in 15 seconds.

Vertical 9:16, captions on, link the full video. Post the same clips to Instagram Reels and
LinkedIn. LinkedIn matters here, because that is where business clients are.

### Step 17. Publish the template (20 min)

Export the workflow or sheet, write a one-page setup guide, list it on Gumroad. Free for
the first five videos to build an email list, then $19 to $49.

### Step 18. Share (15 min)

Post a genuine answer in the Reddit or forum thread that inspired the video, with the
video link only where the rules allow it. One LinkedIn post: the problem, the result,
the link.

### Step 19. Review (15 min after 48 hours, 15 min after 7 days)

| Check | Good | Action if bad |
|---|---|---|
| Click-through rate | above 5% | new thumbnail or title, test again |
| Average view duration | above 40% | look where the graph drops and fix that section type next time |
| Comments asking how to | any | that question is your next video |

## Part F. Script for video 1

**Title:** I automated my invoices in 20 minutes (no code)
**Build:** Gmail label "Invoices" triggers a workflow. An AI step reads the PDF and pulls
vendor, date, amount and due date. A row is added to a Google Sheet. Tool: n8n or Make,
whichever you are faster in.
Target length: 9 to 10 minutes. [SCREEN] lines are recording cues.

---

[SCREEN: an inbox with three new invoice emails. A Google Sheet beside it. Rows appear one
by one as the emails arrive.]

Three invoices just arrived. I didn't open any of them. They're already in my sheet, with
the vendor, the amount, and the due date. This used to take me an hour every Friday.
Today you're going to build the same thing, and it takes about twenty minutes.

[SCREEN: the finished workflow, four boxes connected.]

By the end of this video you'll have this. Four steps, no code. The template is free,
the link is in the description, but build it with me once so you know how to change it.

[SCREEN: manually opening a PDF, copying the vendor name, switching to the sheet, pasting.]

Here's the manual way. Open the email. Open the PDF. Find the vendor. Copy. Switch tabs.
Paste. Find the amount. Copy. Switch. Paste. Multiply that by forty invoices a month. And
every few weeks, you paste a number into the wrong row.

[SCREEN: step label "Step 1 of 4: Label the emails".]

Step one. We need Gmail to tell us which emails are invoices. Create a filter. Anything
with "invoice" in the subject, or a PDF from a known vendor, gets the label Invoices.
This is the only rule in the whole system, so make it a little broad. It's easier to
ignore an extra email than to miss a real invoice.

[SCREEN: step label "Step 2 of 4: Start the workflow".]

Step two. In the automation tool, add a Gmail trigger. Choose the Invoices label. Set it
to check every five minutes. Now send yourself a test invoice and click "fetch test
event". There it is. The email, and the PDF attached.

[SCREEN: step label "Step 3 of 4: Let AI read the PDF".]

Step three is the clever part. First, turn the PDF into text with the extract-from-file
step. Then add an AI step. Here's the prompt, word for word, and it's in the template too.

[SCREEN: the prompt in large text.]

"Read this invoice. Return only JSON with four fields: vendor, invoice_date, amount,
due_date. Dates as year-month-day. Amount as a number with no currency symbol. If a
field is missing, return null."

Two things matter in that prompt. "Return only JSON" stops the AI from chatting.
And "if a field is missing, return null" stops it from inventing a due date that isn't
there. Without that line, it will guess. Ask me how I know.

[SCREEN: the test run output showing the four fields.]

Run it. Vendor, date, amount, due date. Clean.

[SCREEN: step label "Gotcha".]

Now the mistake that cost me half an hour. Some invoices are scanned images, not real
PDFs, so there's no text to extract and the AI gets nothing. The fix: add an "if" check.
If the extracted text is empty, send it to an OCR step first. Two minutes to add, and
it saves you from silent blank rows.

[SCREEN: step label "Step 4 of 4: Write to the sheet".]

Step four. Add a Google Sheets step, choose append row, and map the four fields to your
four columns. Add a fifth column with a link back to the email, so you can always check
the original.

[SCREEN: three fresh test invoices sent, rows appearing.]

Let's test it properly. Three new invoices, three different vendors, one scanned.
Wait for it. One. Two. Three. All four fields, all three rows, including the scanned one.

[SCREEN: workflow switched to active.]

Switch it on, and you're done. From now on, invoices file themselves.

[SCREEN: a quick look at a due-date reminder idea.]

If you want to go one step further, add a daily check that emails you every invoice due
in the next three days. That's the next video.

The template for this build is in the description, free. And if you'd rather have this
set up for your business, there's a link for that too. See you in the next one.
