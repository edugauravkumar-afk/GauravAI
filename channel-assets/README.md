Banner text sits inside YouTube's 1546x423 centre safe area, so it shows on phones, TVs and desktops.
Fonts: Archivo Black and Public Sans (tech), Cinzel and Cormorant Garamond (history), IM Fell English (myths). All SIL Open Font License, from the Google Fonts repository.
`_source/make_art.py` regenerates the images (needs Pillow and the fonts).

Copy-paste text for each channel (description, keywords, bios) is on the playbook page under "Create the channels".
